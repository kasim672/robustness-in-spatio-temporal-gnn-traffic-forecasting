# 📊 Results Directory

All experimental outputs from the robustness benchmark are organized here. Metrics and plots are **committed to git** for full reproducibility; model checkpoints are **`.gitignored`** due to size.

---

## Directory Structure

```
results/
├── metrics/              # JSON files — all numerical results
├── plots/                # PNG figures — all generated visualizations
├── models/               # Model checkpoints (.gitignored)
│   ├── baseline_models/  # ARIMA, LSTM, Random Forest weights
│   └── gnn_models/       # STGCN and DCRNN weights (incl. ablation)
│       ├── dcrnn/
│       └── stgcn/
└── paper_assets/         # LaTeX tables, CSVs, and checklists for the paper
```

---

## 📁 metrics/

Machine-readable JSON files containing all experimental results. These are the **source of truth** for every number in the paper.

| File | Description |
|---|---|
| `METR-LA_baselines_results.json` | Clean-data MAE/RMSE/MAPE for Persistence, Hist. Avg, ARIMA, RF, LSTM on METR-LA |
| `PEMS-BAY_baselines_results.json` | Same metrics for PEMS-BAY |
| `METR-LA_gnn_results.json` | Clean-data results for STGCN and DCRNN on METR-LA |
| `PEMS-BAY_gnn_results.json` | Same for PEMS-BAY |
| `METR-LA_gnn_identity_results.json` | Ablation: GNNs with identity graph (no spatial edges) |
| `METR-LA_gnn_random_results.json` | Ablation: GNNs with random graph |
| `METR-LA_robustness.json` | Multi-seed robustness results (random missing + sensor failure, p=0–0.4) |
| `PEMS-BAY_robustness.json` | Same for PEMS-BAY |
| `METR-LA_sparsity_analysis.json` | Graph properties across sparsity thresholds ε |
| `*_efficiency.json` | Training time and throughput measurements |

### JSON Schema (robustness files)

```json
{
  "model_name": {
    "corruption_type": {
      "ratio": {
        "seeds": {
          "seed_0": { "mae": ..., "rmse": ..., "mape": ... },
          ...
        },
        "mean": { "mae": ..., "rmse": ..., "mape": ... },
        "std": { "mae": ..., "rmse": ..., "mape": ... }
      }
    }
  }
}
```

## Regenerating Results

All results can be regenerated from trained models without retraining:

```bash
# Robustness evaluation
python -u run_robustness.py --dataset METR-LA --n-seeds 5
python -u run_robustness.py --dataset PEMS-BAY --n-seeds 5

# Graph analysis
python -u run_sparsity_analysis.py

# Plots
python plot_robustness.py

# Paper assets (LaTeX tables + CSVs)
python generate_paper_assets.py
```
